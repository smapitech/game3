## Education & Teaching Examples

These repositories contain classroom exercises, student demonstrations,
coding games and learning projects developed for Child's Bridge AI Academy.

- [Typing Adventure](https://github.com/smapitech/typing)  
  Keyboard and typing practice project for young learners.

- [JavaScript Game Lab](https://github.com/smapitech/game)  
  Simple browser games used to teach JavaScript concepts.

- [DOM World](https://github.com/smapitech/DOM-World)  
  Classroom exercises demonstrating DOM manipulation and events.

- [Coding Class Projects](https://github.com/smapitech/classwork)  
  Practical examples and assignments used during live coding classes.

- [Kids Game Collection](https://github.com/smapitech/Games)  
  Small interactive projects designed to make coding lessons engaging.
